# QA - Testes de API ServeRest

Portfólio de QA - Testes de API REST

## Cenários testados (5)
1. POST Criar usuário válido - 201
2. POST Email inválido sem @ - 400 (negativo)
3. POST Email já existente - 400 (negativo)
4. GET Listar usuários - 200



## Como rodar
1. Baixa o arquivo `QA serverRest.postman_collection.json`
2. No Postman > Import > File > seleciona o arquivo
3. Run collection

Ferramentas: Postman, JavaScript
